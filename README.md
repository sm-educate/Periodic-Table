# 🧪 The Amazing Periodic Table of Elements

An interactive, modern, and high-performance Periodic Table web application built with clean HTML5, CSS3, and JavaScript. Designed to make exploring chemistry engaging and accessible for students, educators, and curious minds.

## ✨ Features

- **Standard IUPAC Layout:** Includes main groups and dedicated rows for Lanthanides & Actinides.
- **Instant Search:** Search by element name, chemical symbol, or atomic number.
- **Advanced Filtering:** Filter elements by category, state of matter (Solid, Liquid, Gas, Synthetic), and electron subshell block ($s, p, d, f$).
- **Rich Modal Inspection:** Detailed view for every element featuring:
  - Atomic mass, phase, block, and electron configuration
  - Interactive Bohr electron shell visualizer
  - Discovery history and real-world application highlights
- **Keyboard Shortcuts:** Press `/` to jump to search, `Esc` to close modals.
- **Responsive & Dark UI:** Glassmorphism styling optimized for both mobile and desktop screens.
